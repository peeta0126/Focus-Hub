# UI 이미지 리소스

현재 추적된 WebP는 `hero-night-room.webp`, `weather-night.webp`, `project-tarot.webp`, `project-ai-quiz.webp`, `project-crewspace.webp`입니다. 서비스 화면 캡처가 아닌 UI 일러스트입니다. 사용 경로는 `src/lib/assets.ts`와 각 컴포넌트에서 확인합니다.

- `hero-night-room.webp`
- `weather-night.webp`
- `focus-character.webp`
- `habit-plant.webp`
- `cat-sleep.webp`
- `project-tarot.webp`
- `project-ai-quiz.webp`
- `project-crewspace.webp`

위 목록 중 `focus-character.webp`, `habit-plant.webp`, `cat-sleep.webp`는 현재 포함되지 않은 선택 경로입니다. 없는 파일을 완성된 이미지로 소개하지 않습니다. `AssetImage`는 로드 실패 시 대체 UI를 표시합니다.
